# Freddy AI

Android-приложение с чатом, голосом, пиксельным Фредди и управлением ESP32.

## Установка

Откройте [последний релиз](https://github.com/petrkuzmin811-glitch/FreddyAI/releases/latest).

- **FreddyAI-`версия`.apk** — полная сборка с русской моделью Vosk.
- **FreddyAI-`версия`-update.apk** — компактное обновление. Можно установить поверх предыдущей сборки. Для офлайн-распознавания в этой сборке нужна уже установленная или отдельно скачанная модель Vosk.

Начиная с версии 1.9.21 приложение проверяет GitHub при запуске. Проверить вручную можно через меню **Обновления**. При первой установке из приложения Android попросит разрешить установку для Freddy AI, а затем подтвердить её.
